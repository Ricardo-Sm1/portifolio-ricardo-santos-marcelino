# 🐍 Simuladores Financeiros e Analíticos em Python

## 📝 Descrição do Projeto

Este projeto reúne um conjunto de módulos Python desenvolvidos com foco em **lógica de programação aplicada**, abrangendo cenários do dia a dia como gestão de vendas, análise climática, controle de notas escolares e simulação de investimentos.

Desenvolvido como parte da disciplina de **Lógica de Programação para Python**, cada módulo demonstra o uso prático de estruturas fundamentais como laços de repetição, condicionais, tipagem estática e boas práticas de entrada e saída de dados.

## 📦 Módulos do Projeto

### 🛒 `processar_vendas()`
Processa compras com múltiplos produtos e aplica descontos progressivos automaticamente:
- Desconto de **10%** para compras acima de R$ 500,00
- Desconto de **5%** para compras acima de R$ 200,00
- Validação de preços e quantidades inválidos

### 🌡️ `analisar_clima()`
Analisa temperaturas de uma semana completa (7 dias) e emite alertas:
- Calcula a **média semanal** de temperaturas
- Conta **dias acima de 35°C**
- Emite alerta para condições extremas (acima de 45°C ou abaixo de -5°C)

### 📚 `sistema_notas_turma()`
Gerencia o desempenho escolar de uma turma:
- Calcula a **média** de duas notas por aluno
- Classifica o aluno como **Aprovado**, em **Recuperação** ou **Reprovado**

### 💰 `simulador_poupanca()`
Simula a evolução de um investimento mês a mês com aportes variáveis:
- Aplica **juros compostos** com taxa configurável
- Permite **aportes mensais** personalizados
- Notifica quando a **meta de R$ 10.000,00** é atingida
